## 모델·코드와 맞지 않는 점 (코드 읽기, 실행 안 함, 코드 변경 안 함)

- "교통이용금액 월 2만원까지"는 전용 필드가 없다. 요율 10% 고정이므로 TRANSIT 버킷 2,000원과 결과가 같아 버킷으로 표현하고 원문을 보존한다. 원 미만은 D-03 절사다.
- TELECOM 2,500원 버킷("월 1회")은 문서 결과와 같은 효과를 내는 모델 표현이며 문서 문구가 아니다.
- 유예의 `deemedPerformance` 20만원은 문서 결과와 같은 효과를 내는 모델 표현이며 문서 문구가 아니다.
- `TRANSIT`의 날짜 기준(이용내역서 기재일)은 서비스 단위 필드가 없다.
- 코드와 문서의 전제: `LimitDeductionOrder.PURCHASE_ORDER` 주석과 D-18 설명은 01914만 예로 든다. 01664도 매입 순서를 명시한다.
