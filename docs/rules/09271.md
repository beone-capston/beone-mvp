## 규칙에서 제외한 것

- 티타늄 서비스(발레파킹, 공항라운지 등): 금액 계산 대상이 아니다. 아래 "로더 JSON에 넣지 않은 값"에 기록만 했다.
- K-WORLD 해외 수수료 0.5% 할인(설3): 2019.12.31까지 조건이고 월간 결제 혜택이 아니다.
- 포인트리 인출·캐시백 방법, 연회비, 연체료율, 해외 청구 산식, 설명서 4~8쪽 일반 안내: 혜택 규칙이 아니다.

## 모델·코드와 맞지 않는 점 (코드 읽기, 실행 안 함, 코드 변경 안 함)

- FUEL 산식은 `BenefitCalculation`(요율·정액)으로 표현하지 못한다.
- `excludesBenefitedSales`는 규칙 단위 boolean이다. 09271은 "선택 할인을 받은 건"만 제외이므로 1% 적립 건까지 제외하면 실적이 틀린다. 실적 합산은 아직 구현되지 않았다.
- `requiresSelection`은 있지만 FUEL·STORE의 상호 배타는 전용 필드가 없다. `mutuallyExclusiveWith`는 메모다.
- 해외 실적 매입 완료 기준은 `performanceDateBasis`로 표현하지 못한다.

## 저장소 요약 문서와 다른 점

- [`card-benefit-research.md`](../card-benefit-research.md) 티타늄 절에 없는 내용을 확인했다: "이용 순서대로" 문장, 입점 매장 조건부 제외, 전기·수도·납입금 제외 항목명, 선불전자지급수단 차이.
- 요약과 어긋나는 값은 없다.

## 상품설명서 단독 근거 확인

규칙의 혜택·정책 값은 모두 상품설명서만으로 근거가 선다. 주요거래조건 설명서에만 있는 값은 없다. 설명서에만 있는 것은 `24.11개정` 표기, K-WORLD "UPI" 표현, 일반 금융 안내뿐이고 규칙 값이 아니다. 따라서 시작일은 2024-04-17을 유지한다.

- 주요거래조건 설명서는 URL에 날짜가 없고, 서버 Last-Modified(2026-09-02)가 PDF 생성일(2026-04-01)보다 늦다. 같은 URL의 내용이 바뀔 수 있으므로 위 SHA-256으로 조회 시점 파일을 식별한다.

## 사용자 결정 (2026-11-03)

- 시작일: 사용자 지정 적용 시작일 2024-04-17. 약관 효력일이 아니며 D-01을 해결하지 않는다.
- 최소 금액 0원(조건 없음), 상한은 "상한 없음". 근거 범위는 상품설명서 5쪽, 주요거래조건 설명서 8쪽이다.
- 주유 할인액 = 주유 이용금액 × 100원 ÷ 기준유가(GS칼텍스 고시 휘발유가, 경유·등유·LPG는 휘발유가로 환산). 기준유가 값이 없으면 확인 필요, 원 미만 처리도 확인 필요다.
- 차감 순서는 원문 보존, 값은 확인 필요.

## 선택 입력 (2026-11-03 사용자 결정, R2)

- 미입력(`UNKNOWN`, 확인 필요), 서비스 선택(FUEL 또는 STORE), 선택 없음(`NONE`, 사용자 명시 입력)으로 구분한다. `NONE`이면 FUEL·STORE는 그 거래에 적용되지 않음으로 보고 BASE를 판정한다.
- 실물 카드에 선택 없음 상태가 있는지는 상품설명서로 확인되지 않음. `NONE`은 사용자 입력값이며 가상 포트폴리오·평가 사례용이다. 내 카드 모드에서는 실제 선택을 입력받도록 안내한다.
