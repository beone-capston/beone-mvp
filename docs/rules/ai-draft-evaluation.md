# AI 약관 초안 평가 기록 양식

PRD FR-08 완료 조건 "카드 4종에 대해 수동 규칙 작성과 AI 초안 검토의 수정 항목·검토 시간을 비교한다"를 기록하는 양식입니다(결정 41 후보).

> **상태: 빈 양식.** 측정은 아직 하지 않았습니다. 이 문서의 모든 수치 칸은 비어 있으며, 측정 전 값을 0이나 추정치로 채우지 않습니다.

## 측정 전제

| 항목 | 상태 |
| --- | --- |
| AI 초안 생성 | 실제 AI 호출은 사용자 승인 전이라 하지 않았습니다. 도구는 `tools/rule-draft`(PR #235, 검토 중)입니다. 제공자·모델·호출 수·비용 승인 뒤에 측정합니다. |
| 필드별 비교 | 비교기(`compare`)는 D41-2에서 만듭니다. 그 전에는 아래 "수정 항목" 정의에 따라 사람이 셉니다. |
| 수동 작성 기록 | 현재 `VERIFIED` 규칙 4종은 수동으로 작성·승인했습니다. 다만 당시 작성·검토 시간과 수정 항목 수는 기록하지 않았습니다. 과거 값은 git 이력으로 추정하지 않고 `기록 없음`으로 둡니다. |

## 측정 방법

### 원문

[원문 스냅샷](sources.md)의 상품설명서(1차 근거)와 SHA-256이 같은 파일만 씁니다. 수동 경로와 AI 경로가 같은 원문을 보도록 하기 위해서입니다.

### 수정 항목

검토자가 원문과 대조해 고친 **값 하나**를 1건으로 셉니다. 값 하나는 규칙 JSON의 JSON Pointer 경로 하나로, 자식이 없는 값을 말합니다. 예를 들어 `/limitBuckets/0/tiers/1/monthlyCap`은 1건입니다.

| 종류 | 뜻 |
| --- | --- |
| 변경 | 값이 달라짐. 확정 값 ↔ `{"unresolved": …}` 전환도 포함합니다 |
| 추가 | 초안에 없던 값을 넣음 |
| 삭제 | 초안의 값을 뺌 |
| 근거 없음 | 초안 값에 확인된 원문 근거(쪽·인용)가 없어 검토자가 근거를 찾거나 값을 고쳐야 했던 항목. AI 경로만 셉니다 |

- 프로젝트 관리 필드(`status`, `evaluationOnly`, `sources` 아래, `evidence` 근거 표 번호)는 원문에서 오지 않으므로 수정 항목에서 뺍니다.
- 같은 값을 여러 번 고쳐도 1건입니다.

### 시간

- **방법:** 시작·끝 시각을 분 단위로 적고 쉬는 시간은 뺍니다.
- **작성 시간:** 원문을 읽기 시작해 첫 규칙 JSON을 완성할 때까지입니다. 수동 경로만 해당합니다.
- **검토 시간:** 검토자가 초안(수동 작성본 또는 AI 초안)을 원문과 대조하기 시작해, 고친 결과를 승인할 수 있다고 판단할 때까지입니다.
- **제외:** AI 응답을 기다린 시간과 도구 실행 시간은 검토 시간에 넣지 않고 따로 적습니다.

### 결과 확인

두 경로의 최종 결과를 현재 `VERIFIED` 규칙과 필드별로 비교합니다. 남은 불일치 수를 적고, 그 불일치가 어느 쪽 오류인지 근거 표에 기록합니다. `VERIFIED` 규칙을 고칠 일이 생기면 평가 기록과 별도로, 사람이 근거와 함께 따로 커밋합니다.

### 편향 기록

- **AI 경로 검토 시간:** 현재 4종은 이미 수동 규칙이 있습니다. 같은 사람이 AI 초안을 검토하면 답을 아는 상태라 검토 시간이 짧게 나옵니다. 가능하면 수동 규칙을 작성·검토하지 않은 팀원이 AI 초안을 검토하고, 그렇지 못하면 "검토자 사전 노출" 칸에 적습니다.
- **형식 예시:** AI 도구는 형식 예시로 대상이 아닌 다른 카드의 규칙만 모델에 보여 줍니다. 대상 카드의 수동 규칙은 모델 입력에 들어가지 않습니다.

## 결정 필요

- **수동 경로 재측정:** 과거 기록이 없어 지금은 수동 칸을 채울 수 없습니다. 다른 팀원이 원문만 보고 다시 작성해 수동 경로를 새로 측정할지 정해야 합니다.
- **AI 초안 검토자 배정:** 수동 규칙을 작성·검토하지 않은 팀원을 배정할 수 있는지 정해야 합니다.
