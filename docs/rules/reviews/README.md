# 규칙 초안 승인 기록

[`tools/rule-draft`](../../../tools/rule-draft/README.md)의 `approve` 명령이 남기는 사람 승인 기록을 두는 곳입니다(PRD FR-08, 결정 41).

- **파일:** `<카드ID>-<날짜>.json`. 날짜는 서울 시간 기준입니다. 같은 날 두 번째 기록부터 `-2`, `-3`을 붙이고, 기존 기록은 덮어쓰지 않습니다.
- **내용:** 승인자, 승인 시각(UTC), 비교 결과 파일·초안·수동 규칙의 sha256, 분류별 건수, 수정 항목(경로·전·후·사유)
- **규칙에 미치는 영향 없음:** 이 기록은 규칙 JSON을 바꾸지 않습니다. `VERIFIED` 반영은 사람이 원문과 대조해 `backend/src/main/resources/rules/`의 JSON을 고친 뒤 별도 커밋으로 합니다.
- **현재 상태:** 기록이 아직 없습니다.
- 승인자 칸에는 팀 안에서 알아볼 수 있는 이름이나 GitHub 아이디를 적습니다. 실제 개인정보(연락처 등)는 적지 않습니다.
