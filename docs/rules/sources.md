# 카드 규칙 원문 스냅샷

카드 4종 규칙의 근거가 된 공식 원문을 식별하는 메타데이터입니다. PRD FR-08과 결정 41(후보)의 "원문 스냅샷" 항목에 해당합니다.

- **원문 식별 방법:** 같은 URL의 파일이 바뀔 수 있으므로, 원문은 URL이 아니라 **SHA-256(파일 바이트의 지문)으로 식별합니다**. AI 초안 도구에 넣는 PDF도 아래 SHA-256과 같은 파일이어야 같은 원문으로 봅니다.
- **값의 출처:** 아래 값은 모두 각 카드의 근거 표(`docs/rules/<카드>.md`)에 이미 기록된 값을 옮긴 것입니다. 이 문서에서 새로 조회하거나 계산한 값은 없습니다.
- **값이 다를 때:** 근거 표와 이 문서가 다르면 근거 표가 우선입니다. 확인되지 않은 칸은 `확인 필요`로 둡니다.

## 아직 확인되지 않은 것

| 항목 | 상태 |
| --- | --- |
| 카드 4종 원문의 현재 SHA-256 재확인 | `확인 필요`. 2026-11-03 이후 같은 URL의 파일이 바뀌었는지는 확인하지 않았습니다. |
| AI 초안 도구에 넣을 PDF의 SHA-256 일치 | `확인 필요`. 도구는 입력 파일의 SHA-256을 근거 파일(`source.sha256`)에 남기므로, 실행 뒤 위 표와 대조합니다. |
| 실제 카드의 공식 SKU·약관 버전 일치 | 미결([D-01](../decisions.md)). 이 문서는 해결하지 않습니다. |

## PDF 원본 보관 (기본안)

**기본안: PDF 원본은 저장소에 넣지 않고, 각자 `fixtures/private/rules/<카드ID>/`에 둡니다. 저장소에는 위 메타데이터만 기록합니다.**

| 근거 | 내용 |
| --- | --- |
| 저작권 | 상품설명서는 카드사의 저작물입니다. 공개 저장소에 원문을 다시 배포하는 것은 이용 허락을 확인하지 않은 행위가 됩니다. 메타데이터(URL·문서번호·SHA-256)만으로 같은 파일을 다시 받아 식별할 수 있습니다. |
| 공개 저장소 | 저장소는 공개 범위로 운영됩니다. 커밋된 파일은 이력에 남아 지울 수 없으므로 넣지 않는 쪽을 기본으로 둡니다. |
| 기존 관례 | [규칙 데이터 안내](README.md)는 이미 "공식 PDF는 저장소에 넣지 않고 URL과 SHA-256만 적는다"고 정했습니다. 이 기본안은 그 관례를 AI 초안 도구 입력에도 적용한 것입니다. |
| git 제외 | `fixtures/private/`는 루트 `.gitignore`로 제외됩니다. 다만 이 경로는 실제 민감정보(실계정 응답·개인 거래)를 두는 곳이 아닙니다(CLAUDE.md 보안). 공개된 상품설명서 PDF는 민감정보가 아니므로 여기에 두어도 이 원칙과 충돌하지 않습니다. |

확인 절차는 다음과 같습니다.

```bash
# 공식 URL에서 받은 파일을 fixtures/private/rules/<카드ID>/에 둔 뒤
shasum -a 256 fixtures/private/rules/09174/09174__prdctOpmn_20260714.pdf
# 출력이 위 표의 SHA-256과 다르면 원문이 바뀐 것이다. 규칙을 고치지 말고 근거 표에 기록한 뒤 검토한다.
```

최종안(예: 팀 공유 드라이브에 두기)은 PR에서 근거와 함께 정합니다. 그 전까지는 위 기본안을 따릅니다.
