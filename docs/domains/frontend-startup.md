# 프런트엔드 앱 시작

[AppStartup](../../frontend/src/startup/AppStartup.tsx)은 페이지 시작에만 [브랜드 스플래시](../../frontend/src/startup/BrandSplash.tsx)를 덮습니다. 900 × 760 파란 로고 원본의 심볼과 워드마크를 사용하고, 승인된 SVG 숫자 1 경로를 별도로 축소합니다. 최종 심볼은 원본 PNG의 픽셀을 표시합니다.

[타임라인](../../frontend/src/startup/splashTiming.ts)은 브라우저 페이지 이동 시작 기준입니다. 800ms에 심볼을 완성하고, 1100ms까지 워드마크를 표시합니다. 심볼 완성 시 숫자 1의 오른쪽 모서리를 따라 500ms 동안 빛이 한 번 내려갑니다. 완성 로고를 450ms 유지하고 1550ms부터 페이드아웃합니다. 기본 종료 시점은 1900ms입니다. 모션 감소 설정에서는 정적 로고를 최대 180ms 표시합니다. 애니메이션 이벤트가 없어도 종료 타이머가 덮개를 제거하고, 앱 복귀 시에도 경과 시간을 다시 확인합니다.

[AuthEntry](../../frontend/src/auth/AuthEntry.tsx)는 시작부터 기존 세션 조회를 담당합니다. 스플래시 동안 아래 화면의 포커스와 접근성 탐색을 차단하고, 종료 시 차단을 해제합니다. 세션이 지연되면 로그인 폼을 표시하되 판정 전까지 제출을 잠급니다. 조회 오류는 폼의 재시도 안내로 이어집니다. 비밀번호 재설정 링크에서는 스플래시를 생략합니다.

2초 목표는 프런트엔드 스플래시 노출과 다음 화면 표시를 다룹니다. Android 시스템 시작, WebView 초기화 및 실제 네트워크 콜드 스타트는 별도 검증 대상입니다.
